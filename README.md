DUNAMIS - Sistema de Gestión de Proyectos
Sistema web desarrollado con Node.js, Express y SQL Server para la administración de proyectos, usuarios, recursos y reportes.

📋 Descripción
DUNAMIS es un sistema diseñado para centralizar la gestión de proyectos dentro de una organización, permitiendo administrar usuarios, recursos, reportes y el seguimiento de proyectos desde una interfaz web.

🚀 Tecnologías Utilizadas
HTML5
CSS3
JavaScript
Node.js
Express
SQL Server
⚙️ Funcionalidades
Gestión de Usuarios
Administración de usuarios.
Control de acceso al sistema.
Gestión de Proyectos
Registro de proyectos.
Consulta y seguimiento de proyectos.
Administración del estado de los proyectos.
Gestión de Recursos
Asignación y administración de recursos.
Reportes
Consulta y generación de reportes.
🎨 Diseño
La interfaz utiliza una paleta de color verde debido a los requerimientos definidos para el proyecto académico, buscando transmitir organización, productividad y crecimiento.

▶️ Ejecución
npm install
node server.js
✅ Requisitos
Node.js
SQL Server
